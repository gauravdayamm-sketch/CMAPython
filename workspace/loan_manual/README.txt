PUT THE LOAN MANUAL HERE  (once)
================================

Drop the bank's Manual on Loans & Advances as a .md or .txt file.
It is indexed on the first run and then LEFT ALONE — committee
questions in the memo cite its chapters automatically.

You only need to do this once. To load an updated manual later,
replace the file here and run:   cma manual --index "<path>"
(or delete db\cma.sqlite's manual index and re-run).

This file stays on this machine and is never sent anywhere.
