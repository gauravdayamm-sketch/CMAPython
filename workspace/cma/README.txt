PUT CMA DATA HERE
=================

Drop ONE borrower's CMA files in this folder, then double-click
RUN_CMA.bat in the main folder.

Accepted:
  - LLMS system exports (all three, keep the system file names):
      <Name> CMA_Balance_Sheet.xls
      <Name> CMA_Operating_Statement.xls
      <Name> CMA_Performance_And_Financial_Indicators.xls   (optional)
    .csv versions also work.
  - OR a filled CMA workbook (.xlsx).

The borrower's name is read from these files and used for everything
else in the run. Process one borrower at a time — clear this folder
before the next borrower.
