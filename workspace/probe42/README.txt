PUT PROBE42 / MCA DOWNLOADS HERE
================================

Drop any of these PDFs for the SAME borrower (the tool recognises each
type automatically):

  - Probe42 company report PDF   → MCA status, charges (who else has
                                   lent?), auditor-qualified flag, cases
  - Form AOC-4 (filed with MCA)  → ties the FILED financials against the
                                   CMA; a material mismatch is flagged as
                                   concealment (EWS #18)
  - Audited annual report (scan) → read for the auditor's OPINION only;
                                   figures are never taken from a scan

Optional — leave empty if you have nothing to add. Clear before the
next borrower.
